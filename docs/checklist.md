# BuildLog MVP 개발 체크리스트

## 1. 사용 방법

이 문서는 `spec.md`의 기능을 실제 개발 작업과 확인 항목으로 연결합니다.

- `[x]`: Phase 0에서 확인을 마친 항목
- `[ ]`: 해당 개발 Phase에서 구현하고 확인할 항목
- 기능 동작이 다르게 적힌 문서가 있으면 `spec.md`를 우선합니다.
- 새로운 기능은 이 목록에 임의로 추가하지 않습니다.

## 5. 공통 권한 기준

| 대상 | 읽기 | 변경 |
| --- | --- | --- |
| 비공개 기록 | 작성자만 | 작성자만 |
| 공개 공부·할 일·오류 기록 | 로그인 사용자 | 작성자만 |
| 댓글 | 로그인 사용자 | 댓글 작성자가 수정·삭제, 기록 작성자가 삭제 |
| 좋아요 | 로그인 사용자 | 자신이 누른 좋아요만 취소 |
| 신고 | 신고한 사실은 저장 | 운영자만 신고 목록·내용 확인 |

- [ ] 모든 권한을 React 화면과 FastAPI 서버에서 각각 검사합니다.
- [ ] 로그인하지 않은 사용자는 공개 기록을 포함한 기록 화면에 접근할 수 없습니다.
- [ ] 비공개 기록이 목록, 검색, 직접 주소 접근으로 노출되지 않습니다.

## 6. 입력 조건 표

| 기능 | 입력 | 조건 |
| --- | --- | --- |
| 회원가입 | 이메일 | 일반 이메일 형식, 중복 불가 |
| 회원가입 | 비밀번호 | 8~64자 |
| 회원가입·변경 | 닉네임 | 2~20자, 한글·영문·숫자·밑줄, 중복 불가 |
| 공부 기록 | 제목 | 1~100자 |
| 공부 기록 | 내용 | 1~5,000자 |
| 할 일 | 제목 | 1~100자 |
| 오류 기록 | 오류 제목 | 1~100자 |
| 오류 기록 | 오류 내용 | 1~5,000자 |
| 오류 기록 | 해결 방법 | 비워둘 수 있음, 입력 시 1~5,000자 |
| 댓글 | 내용 | 1~500자 |
| 신고 | 이유 | 1~500자 |

- [ ] 문자열 입력의 앞뒤 공백을 제거합니다.
- [ ] 공백만 입력한 값은 빈 값으로 처리합니다.
- [ ] 저장 실패 시 `spec.md`에서 정한 입력값을 유지합니다.
