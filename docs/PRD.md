# BuildLog 제품 요구사항 문서(PRD)

## 1. 문서 소개

이 문서는 BuildLog의 첫 번째 버전을 만들기 위한 제작 주문서입니다. 무엇을 왜 만들고, 사용자가 무엇을 할 수 있어야 하며, 어디까지 완성해야 하는지를 설명합니다.

이 문서는 `docs/mvp.md`에서 정한 범위와 이후 확정한 세부 조건을 다룹니다.

---

## 2. 서비스 한눈에 보기

BuildLog는 공부와 프로젝트에 관한 기록을 한곳에서 관리하는 웹사이트입니다.

사용자는 다음 세 종류의 기록을 남길 수 있습니다.

1. 오늘 배우거나 작업한 내용을 적는 **공부 기록**
2. 앞으로 공부하거나 작업할 내용을 적는 **할 일**
3. 발생한 문제와 해결 방법을 적는 **오류 기록**

BuildLog에는 여러 사용자가 가입할 수 있습니다. 각 사용자의 기록은 기본적으로 본인만 볼 수 있으며, 사용자가 공개로 바꾼 기록은 다른 사용자도 볼 수 있습니다.

첫 번째 버전은 화려한 디자인보다 기록을 저장하고 다시 찾는 기본 기능을 안정적으로 제공하는 데 집중합니다.

---

## 3. 누가 사용하는 서비스인가요?

BuildLog의 주요 사용자는 다음과 같습니다.

- 오늘 무엇을 공부했는지 꾸준히 기록하고 싶은 사람
- 앞으로 할 공부나 프로젝트 작업을 정리하고 싶은 사람
- 프로그래밍 오류와 해결 방법을 모아두고 싶은 사람
- 예전에 해결한 오류를 나중에 다시 찾아보고 싶은 사람
- 자신의 기록을 컴퓨터와 휴대폰에서 확인하고 싶은 사람
- 도움이 되는 기록을 다른 사용자에게 공개하고 싶은 사람

BuildLog는 한 사람만 사용하는 개인용 프로그램이 아닙니다. 여러 사람이 각자 회원가입하여 자신의 기록을 관리하는 서비스입니다.

---

## 4. 어떤 불편을 해결하려고 하나요?

### 4.1 기록이 여러 곳에 흩어지는 문제

공부한 내용은 메모장에 있고, 오류 해결 과정은 AI 대화에 있으며, 할 일은 또 다른 앱에 있으면 나중에 어디에 적었는지 찾기 어렵습니다. BuildLog는 이런 기록을 한곳에 모읍니다.

### 4.2 시간이 지나면 공부한 내용을 잊는 문제

사용자는 공부 기록을 날짜와 함께 남기고, 나중에 목록이나 검색을 통해 다시 확인할 수 있습니다.

### 4.3 해야 할 일과 끝낸 일을 구분하기 어려운 문제

사용자는 해야 할 일을 적고 완료 여부를 체크할 수 있습니다. 남은 일과 완료한 일을 나누어 볼 수 있습니다.

### 4.4 같은 오류를 다시 해결해야 하는 문제

사용자는 오류 내용과 해결 방법을 함께 기록할 수 있습니다. 아직 해결하지 못한 오류도 저장해 두었다가 나중에 해결 방법을 추가할 수 있습니다.

### 4.5 내 기록과 공개할 기록을 구분하기 어려운 문제

모든 기록은 기본적으로 비공개로 저장됩니다. 사용자가 원할 때만 공개로 바꿀 수 있습니다.

---

## 5. 사용자가 각 기능으로 무엇을 할 수 있나요?

### 5.1 회원가입과 로그인

사용자는 다음 정보를 입력하여 회원가입할 수 있습니다.

- 이메일: 올바른 이메일 형식, 최대 254자, 중복 불가
- 비밀번호: 8자 이상 64자 이하
- 닉네임: 2자 이상 20자 이하, 한글·영문·숫자·밑줄만 사용, 중복 불가

가입에 성공하면 로그인 화면으로 이동합니다. 가입한 이메일과 비밀번호로 로그인할 수 있으며, 로그인에 성공하면 홈 화면으로 이동합니다. 로그인한 사용자는 자신의 기록을 만들고 관리할 수 있습니다.

- 이미 가입된 이메일이나 닉네임은 다시 사용할 수 없습니다.
- 로그인 실패 시 이메일과 비밀번호 중 어느 것이 틀렸는지는 구분하지 않고 함께 안내합니다.
- 사용자는 가입 후 닉네임을 변경할 수 있으며, 변경할 닉네임에도 같은 규칙을 적용합니다.

다른 사용자는 나의 비공개 기록을 볼 수 없어야 합니다.

첫 번째 버전에서는 이메일 확인과 비밀번호 찾기를 제공하지 않습니다.

### 5.2 기록의 공개 범위

공부 기록, 할 일, 오류 기록에는 각각 공개 여부가 있습니다.

- 새 기록은 기본적으로 `비공개`로 저장합니다.
- 비공개 기록은 작성자 본인만 볼 수 있습니다.
- 작성자는 자신의 기록을 `공개`로 바꿀 수 있습니다.
- 공개 기록은 다른 사용자가 볼 수 있습니다.
- 작성자는 공개 기록을 다시 비공개로 바꿀 수 있습니다.
- 공개 기록을 비공개로 바꾸면 기존 댓글과 좋아요는 삭제하지 않고 숨깁니다. 다시 공개하면 이전 댓글과 좋아요를 복원합니다.

### 5.3 공부 기록

공부 기록은 오늘 배우거나 작업한 내용을 남기는 기능입니다.

#### 저장하는 정보

| 항목 | 규칙 |
| --- | --- |
| 제목 | 1자 이상 100자 이하로 입력합니다. |
| 내용 | 1자 이상 5,000자 이하로 입력합니다. |
| 공개 여부 | 기본값은 비공개입니다. |
| 작성 날짜와 시간 | 기록을 만들 때 자동으로 저장합니다. |
| 수정 날짜와 시간 | 기록을 수정할 때 자동으로 저장합니다. |

#### 사용자가 할 수 있는 일

- 공부 기록 만들기
- 내가 작성한 공부 기록 목록 보기
- 공부 기록의 자세한 내용 읽기
- 공부 기록 수정하기
- 공부 기록 삭제하기
- 공부 기록을 공개 또는 비공개로 바꾸기
- 내 공부 기록을 제목과 내용으로 검색하기
- 공개된 공부 기록 검색하기

내 공부 기록 목록은 최근에 작성한 기록부터 보여줍니다.

### 5.4 할 일

할 일은 앞으로 공부할 내용이나 프로젝트에서 해야 할 작업을 적는 기능입니다.

예: `저장 버튼 만들기`, `파이썬 복습하기`

#### 저장하는 정보

| 항목 | 규칙 |
| --- | --- |
| 제목 | 1자 이상 100자 이하로 입력합니다. |
| 완료 여부 | 기본값은 미완료이며, 미완료와 완료 사이에서 변경할 수 있습니다. |
| 공개 여부 | 기본값은 비공개입니다. |
| 완료 날짜와 시간 | 완료로 체크할 때 자동으로 저장합니다. |
| 수정 날짜와 시간 | 내용을 수정할 때 자동으로 저장합니다. |

#### 사용자가 할 수 있는 일

- 할 일 만들기
- 할 일 완료 체크하기
- 완료한 할 일을 다시 미완료로 바꾸기
- 할 일 수정하기
- 할 일 삭제하기
- 할 일을 공개 또는 비공개로 바꾸기
- 할 일을 `전체`, `남은 일`, `완료한 일`로 나누어 보기

할 일 목록은 완료하지 않은 항목을 먼저 보여줍니다. 상태가 같다면 최근에 작성한 항목부터 보여줍니다.

완료한 일을 다시 미완료로 바꾸면 완료 날짜와 시간을 지웁니다. 할 일 검색은 첫 번째 버전에서 제공하지 않습니다.

마감일과 중요도는 첫 번째 버전에서 만들지 않습니다.

### 5.5 오류 기록

오류 기록은 문제가 생겼을 때 오류 내용과 해결 과정을 남기는 기능입니다. 아직 해결하지 못한 오류도 먼저 저장할 수 있습니다.

#### 저장하는 정보

| 항목 | 규칙 |
| --- | --- |
| 오류 제목 | 1자 이상 100자 이하로 입력합니다. |
| 오류 내용 | 1자 이상 5,000자 이하로 입력합니다. |
| 해결 방법 | 해결 전에는 비워둘 수 있습니다. 입력한다면 1자 이상 5,000자 이하로 작성합니다. |
| 해결 여부 | 기본값은 미해결이며, 미해결과 해결 사이에서 변경할 수 있습니다. |
| 공개 여부 | 기본값은 비공개입니다. |
| 해결 날짜와 시간 | 해결 상태로 바꿀 때 자동으로 저장합니다. |
| 수정 날짜와 시간 | 내용을 수정할 때 자동으로 저장합니다. |

#### 사용자가 할 수 있는 일

- 오류 기록 만들기
- 해결하지 못한 오류를 미해결 상태로 보관하기
- 해결한 뒤 해결 방법 작성하기
- 해결된 오류를 다시 미해결로 바꾸기
- 오류 기록 수정하기
- 오류 기록 삭제하기
- 오류 기록을 공개 또는 비공개로 바꾸기
- 오류 기록을 `전체`, `미해결`, `해결`로 나누어 보기
- 내 오류 기록을 제목과 내용으로 검색하기

오류 기록 목록은 최근에 작성한 기록부터 보여줍니다.

오류를 해결 상태로 바꾸려면 해결 방법을 반드시 입력해야 합니다. 해결된 오류를 다시 미해결로 바꾸면 해결 날짜와 시간을 지웁니다. 검색 대상은 오류 제목과 오류 내용이며 해결 방법은 검색하지 않습니다.

### 5.6 공개 기록

로그인한 사용자는 다른 사용자가 공개한 공부 기록, 할 일, 오류 기록을 한곳에서 모아볼 수 있습니다.

- 공개 기록의 자세한 내용 보기
- 공개된 공부 기록 검색하기
- 공개 공부 기록과 공개 오류 기록에 댓글 작성하기
- 공개 공부 기록과 공개 오류 기록에 좋아요 누르기

공개 기록은 최근 작성한 순서로 보여주며, 공부 기록·할 일·오류 기록 종류별로 걸러볼 수 있습니다.

- 댓글과 좋아요는 공개 공부 기록과 공개 오류 기록에 적용합니다.
- 댓글과 좋아요는 로그인한 사용자만 사용할 수 있습니다.
- 댓글은 1자 이상 500자 이하이며 빈 댓글은 등록할 수 없습니다.
- 댓글에는 작성자의 닉네임과 작성 시간을 표시하고, 오래된 댓글부터 보여줍니다.
- 답글은 첫 번째 버전에서 제공하지 않습니다.
- 댓글 작성자는 자신의 댓글을 수정·삭제할 수 있습니다.
- 기록 작성자는 자신의 공개 기록에 달린 댓글을 삭제할 수 있습니다.
- 좋아요는 한 계정이 같은 기록에 한 번만 누를 수 있고, 다시 눌러 취소할 수 있습니다.
- 공개 기록에는 좋아요 개수를 표시합니다.

### 5.7 신고

로그인한 사용자는 공개 기록이나 댓글을 신고할 수 있습니다.

- 신고 이유는 1자 이상 500자 이하로 입력합니다.
- 한 사용자는 같은 대상을 한 번만 신고할 수 있습니다.
- 신고만으로 대상 기록이나 댓글을 자동 삭제하지 않습니다.
- 신고 내용은 일반 사용자에게 공개하지 않습니다.
- 운영자만 신고 목록과 내용을 확인할 수 있습니다.
- 첫 버전에서는 별도의 신고 처리 상태를 만들지 않습니다.
- 대상 기록이 비공개로 바뀌어도 운영자는 기존 신고를 확인할 수 있습니다.

### 5.8 검색과 목록 정리

첫 번째 버전에서 확정된 검색 범위는 다음과 같습니다.

| 대상 | 검색할 내용 |
| --- | --- |
| 내 공부 기록 | 제목과 내용 |
| 내 오류 기록 | 제목과 내용 |
| 공개 공부 기록 | 제목과 내용 |

검색어가 비어 있으면 전체 목록을 보여주며, 검색 결과는 최근 작성한 기록부터 보여줍니다. 로그인한 사용자만 공개 기록을 검색할 수 있습니다.

내 할 일 검색은 제공하지 않습니다. 공개 공부 기록은 제목과 내용, 공개 할 일은 제목, 공개 오류 기록은 오류 제목·내용·해결 방법으로 검색합니다.

---

## 6. 어떤 화면이 필요한가요?

확정한 디자인 원칙에 따라 첫 번째 버전에는 다음 화면이 필요합니다.

### 6.1 회원가입 화면

- 이메일, 비밀번호, 닉네임을 입력합니다.
- 입력한 정보로 계정을 만듭니다.

### 6.2 로그인 화면

- 이메일과 비밀번호를 입력합니다.
- 가입한 계정으로 로그인합니다.

### 6.3 홈 화면

- 로그인한 사용자가 자신의 기록을 확인하는 시작 화면입니다.
- 로그인한 사용자가 자신의 기록 기능으로 이동할 수 있습니다.

### 6.4 공부 기록 화면

- 내 공부 기록 목록을 봅니다.
- 최근에 작성한 순서로 기록을 봅니다.
- 제목과 내용으로 기록을 검색합니다.
- 새 기록을 작성합니다.
- 기록의 자세한 내용을 읽습니다.
- 내 기록을 수정하거나 삭제합니다.
- 내 기록의 공개 여부를 바꿉니다.

목록과 상세 화면은 나누고, 작성과 수정은 같은 형태의 화면을 사용합니다.

### 6.5 할 일 화면

- 할 일 목록을 봅니다.
- 새 할 일을 작성합니다.
- 완료 여부를 체크합니다.
- 할 일을 수정하거나 삭제합니다.
- 할 일의 공개 여부를 바꿉니다.
- 전체, 남은 일, 완료한 일로 나누어 봅니다.

### 6.6 오류 기록 화면

- 오류 기록 목록을 봅니다.
- 제목과 내용으로 오류 기록을 검색합니다.
- 전체, 미해결, 해결 상태로 나누어 봅니다.
- 새 오류 기록을 작성합니다.
- 오류 기록의 자세한 내용을 읽습니다.
- 해결 방법과 해결 상태를 수정합니다.
- 오류 기록을 삭제합니다.
- 오류 기록의 공개 여부를 바꿉니다.

목록과 상세 화면은 나누고, 작성과 수정은 같은 형태의 화면을 사용합니다.

### 6.7 공개 기록 화면

- 다른 사용자가 공개한 기록을 모아봅니다.
- 공개 기록의 자세한 내용을 읽습니다.
- 확정된 범위에서 공개 공부 기록을 검색합니다.
- 공개 기록에 댓글과 좋아요를 사용합니다.

공개된 공부 기록, 할 일, 오류 기록을 최신순으로 보여주며 기록 종류별 필터를 제공합니다.

### 6.8 신고 및 운영자 화면

- 로그인한 사용자는 공개 기록과 댓글을 신고합니다.
- 운영자는 신고 목록과 신고 내용을 확인합니다.
- 일반 사용자는 신고 목록을 볼 수 없습니다.

### 6.9 공통 화면 조건

- 화면은 단순하고 알아보기 쉬워야 합니다.
- 컴퓨터와 휴대폰 크기에 맞게 화면 구성이 자동으로 조정되어야 합니다.
- 밝은 배경과 파란색 강조색, 읽기 쉬운 기본 글꼴을 사용합니다.
- 어두운 화면은 첫 번째 버전에서 지원하지 않습니다.
- 입력이 잘못되면 사용자가 입력한 내용을 유지하고 해당 항목 아래에 이유를 보여줍니다.

## 7. 어디까지 되면 첫 번째 버전이 완성된 것인가요?

다음 조건을 모두 만족하면 BuildLog의 첫 번째 버전이 완성된 것으로 봅니다.

### 7.1 회원 기능

- 사용자가 이메일, 비밀번호, 닉네임으로 회원가입할 수 있습니다.
- 가입한 이메일과 비밀번호로 로그인할 수 있습니다.
- 로그인한 사용자가 자신의 기록을 관리할 수 있습니다.
- 사용자마다 비공개 기록이 분리되어 있습니다.
- 다른 사용자가 나의 비공개 기록을 볼 수 없습니다.

### 7.2 공부 기록

- 공부 기록을 만들 수 있습니다.
- 내 공부 기록 목록을 최근 작성 순서로 볼 수 있습니다.
- 공부 기록을 자세히 읽고 수정하고 삭제할 수 있습니다.
- 공부 기록의 공개 여부를 바꿀 수 있습니다.
- 내 공부 기록을 제목과 내용으로 검색할 수 있습니다.
- 공개된 공부 기록을 검색할 수 있습니다.

### 7.3 할 일

- 할 일을 만들고 수정하고 삭제할 수 있습니다.
- 할 일의 완료 여부를 바꿀 수 있습니다.
- 완료로 바꾼 시간이 자동으로 저장됩니다.
- 전체, 남은 일, 완료한 일로 나누어 볼 수 있습니다.
- 완료하지 않은 일이 먼저 보이며, 같은 상태에서는 최근 항목이 먼저 보입니다.
- 할 일의 공개 여부를 바꿀 수 있습니다.

### 7.4 오류 기록

- 오류를 미해결 상태로 저장할 수 있습니다.
- 나중에 해결 방법을 작성하고 해결 상태로 바꿀 수 있습니다.
- 해결로 바꾼 시간이 자동으로 저장됩니다.
- 오류 기록을 읽고 수정하고 삭제할 수 있습니다.
- 전체, 미해결, 해결 상태로 나누어 볼 수 있습니다.
- 내 오류 기록을 제목과 내용으로 검색할 수 있습니다.
- 오류 기록의 공개 여부를 바꿀 수 있습니다.

### 7.5 공개 기록과 사용 환경

- 세 종류의 기록이 기본적으로 비공개로 저장됩니다.
- 사용자가 원하는 기록을 공개로 바꿀 수 있습니다.
- 공개 기록을 모아보는 화면이 있습니다.
- 공개 공부 기록과 공개 오류 기록에 댓글을 작성하고 좋아요를 사용할 수 있습니다.
- 로그인한 사용자가 공개 기록과 댓글을 신고할 수 있습니다.
- 운영자만 신고 목록과 내용을 확인할 수 있습니다.
- 주요 기능을 컴퓨터와 휴대폰에서 사용할 수 있습니다.

## 9. 개발 구성

- 화면: React와 TypeScript
- 서버: Python과 FastAPI
- 실제 서비스 데이터베이스: Supabase의 PostgreSQL
- 자동 테스트 데이터베이스: SQLite3
- 회원가입과 로그인: FastAPI 서버에서 처리
- 데이터베이스 접근: React가 Supabase에 직접 접근하지 않고 FastAPI를 통해 처리
